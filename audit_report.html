AUDIT FINDINGS

Current Website Flaws & Performance Bottlenecks

An automated diagnosis of the live website https://yescollege.com.au/ conducted using Google PageSpeed Insights (Nov 14, 2026) highlights critical structural, performance, and conversion vulnerabilities:

FIGURE 1: Google PageSpeed Insights Report for Current Site (yescollege.com.au) — Performance Score: 60/100 (Orange / Poor) FAILING CORE WEB VITALS

Issue 1: Sluggish Mobile Experience (60/100)

  • Largest Contentful Paint (LCP) > 4.2s: Students wait over 4 seconds before the main hero banner renders on 4G/mobile devices.
  • Heavy JavaScript & CSS Bloat: WordPress plugins (Elementor, WooCommerce, LearnPress) inject unneeded scripts on every single page.
  • High Mobile Bounce Rate: Visitors abandon the page before finding course details or entry requirements.

Issue 2: Sub-Optimal SEO & Missing Course Schema (85/100)

  • Missing Schema.org Course JSON-LD: Google cannot display rich snippets (duration, fees, CRICOS code, AQF level) in search results.
  • Unoptimized Meta Descriptions: Missing or duplicate page titles and descriptions hurt ranking against rival Sydney colleges.
  • No XML Course Hierarchy: Course URLs lack structured breadcrumbs and educational organization markup.

Issue 3: Enrolment Funnel Leaks & Friction

  • Buried Static PDF Downloads: Students are forced to download raw PDF files for handbooks and application forms rather than completing digital forms.
  • Cluttered Navigation Menus: Multi-level dropdowns are difficult to navigate on smartphones and tablets.
  • Zero Interactive Course Filtering: No quick search by discipline, level, or campus location.

Issue 4: Security & Maintenance Vulnerabilities

  • Plugin Vulnerability Vectors: WordPress plugins require constant security patches to prevent brute-force attacks and SQL injections.
  • Lack of Modern Edge Caching: Dynamic PHP database queries slow down international visitors accessing the site from overseas.
  • No Privacy-First Data Isolation: Web forms store data in WordPress databases without enterprise-grade encryption.
